Saya buka DevTools dengan menekan Ctrl + Shift + I atau F12. DevTools terbagi menjadi beberapa bagian:

Elements: melihat dan mengubah HTML atau CSS secara langsung.  
Console: menampilkan pesan atau error JavaScript pada halaman.  
Network: memantau respon situs dan menemukan masalah seperti error 404.  

Pada praktikum, saya sengaja menulis salah pada atribut href di CSS. Ketika saya periksa lewat DevTools, muncul error 404 yang menandakan file CSS tidak ada.  

Itulah refleksi saya tentang penggunaan DevTools yang saya pelajari pada 10 September 2026.
